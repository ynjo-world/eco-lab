02 개념

어필리에이트란?

내 링크로 판매가 일어났을 때만, 판매액의 일부를 수수료로 받는 방식
  • CPS(Cost Per Sale) — 노출이 아니라 '판매'에만 과금
  • 1996년 아마존 어소시에이트 시작, 30년 검증 모델
  • 구조: 판매자 → 플랫폼 → 크리에이터(나) → 소비자
본질

본질 = 관심이 모이는 곳(SNS)과 상품(커머스)을 잇는 다리

💬
생각해 볼 질문

03 플랫폼

쿠팡파트너스(쿠파스)

특징내용
진입장벽쿠팡 계정만 있으면 가입. 팔로워 조건 없음
24시간 쿠키클릭 후 24시간 추적. 다른 상품 사도 내 실적
정산월 단위 집계 → 익월 계좌 입금
내 링크 = 상품 추천이 아니라 '쿠팡으로 들어가는 문'

수익 공식

<인플루언서의 특성과 소비자 속성이 팔로우에 미치는 영향>

"남성은 인플루언서 성별에 영향받지 않으나,
여성은 여성 인플루언서를 유의미하게 팔로우"
  • 동성 편중 = 여성 소비자에게서 뚜렷
  • 여성은 전문성·호감성 + 친밀성 중시 → 말투 전략의 근거

나노바나나

  • "페르소나가 이 상품을 쓰는 장면"을 프롬프트로 생성

  • 일상 스냅처럼 약간 허술하게 = 진짜처럼 보임

Grok

  • Grok 사진에 애니메이션 효과 주기 버튼 하나
  • 머리카락 날림, 카메라 미세 흔들림 정도의 움직임
  • 움직이는 콘텐츠 = 스크롤을 멈춤 = 체류시간↑ = 노출↑

스레드체

08 동선

링크 -> 댓글

본문에 링크 ❌ → 발행 즉시 셀프 댓글 ⭕
  1. 알고리즘 — 본문에 외부 링크 있으면 도달 억제 경향
  2. 동선 — "어디서 사?" 하는 순간 제일 먼저 여는 곳 = 댓글창
정리

본문은 순수 콘텐츠로 → 알고리즘이 밀어줌
첫 댓글에 링크 → 관심 식기 전에 클릭유도

09 타이밍

시즈널 전략

특수일 = 노출↑ + 반응↑ + 객단가↑ 가 동시에

어린이날 데이터

  • 선물 예산 평균 9.5만 원 (10년 전 4.9만 → 2배)
  • 받고 싶은 선물 1위 = 전자기기 35% (스마트폰 포함 44.5%)
어린이날 = 수십만~백만 원대 노트북·가전이 팔리는 날
3만 원 티셔츠 vs 100만 원 노트북 → 수수료 자릿수가 다름
전술

D-2주 미리 깔기 · 특수일엔 고단가로 스위칭 · "뭐 사지?"에 답하는 글

(화이트데이 · 어버이날 · 빼빼로데이 · 블프 · 설/추석 동일 적용)

12 컴플라이언스

지켜야 할 것 3가지

  1. 대가성 표시 — "쿠팡 파트너스 활동으로 수수료를 제공받습니다" (미표기 = 제재 사유)
  2. 플랫폼 정책 준수 — 계정이 날아가면 전부 사라짐
  3. 과장 금지 — 표시광고법
이건 비용이 아니라 보험
13 요약

요약

  1. 어필리에이트 = 팔릴 때만 과금되는 30년 모델
  2. 글보다 숫자 먼저 — 답은 "2030 여성 + 동성 화자"
  3. 나노바나나 → Grok → 스레드체 3단 공정
  4. 링크는 1순위 댓글, 특수일엔 고단가
  5. 네이버 · 토스 · 겜스고로 확장 가능
감이 아니라 데이터로 시작하면,
개인도 마케팅 팀처럼 움직일 수 있다
🎯
마무리 토론

오늘 배운 '데이터 → 페르소나 → 콘텐츠 → 동선 → 시즌' 공식을, 내가 잘 아는 관심사 하나에 적용한다면 — 어떤 페르소나로, 어떤 특수일을 노리겠습니까? 그리고 그때 가장 먼저 검증해야 할 '숫자'는 무엇일까요?
